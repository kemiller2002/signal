## Behaviour changes found and how each was handled

1. **Arca 0.7 reconciles a failed ref update and resends once (ARCA-OUT-001).** The old ULI-A07 test expected a single 503 to leave the store offline, which encoded Arca 0.5 behaviour. The ADM-009 source forbids *blind* retry but requires reconciliation before retry, which is what Arca 0.7 does. The test is split in two:
   - **(a) A single 503:** the change lands exactly once. The test asserts 2 ref updates, 1 new commit and 1 group record.
   - **(b) Two 503s:** the original honesty checks still hold: offline, read-only, nothing kept, and Refresh recovers.
2. **Forma 0.13.0 fixed the best-worst long-word overflow.** The ULI-L05 EXCEPTION test was written to start failing when Forma fixed this, and it is now an ordinary assertion.
3. **Forma 0.13.0 regression found by manual visual review, not by the existing suite:** below 24em the record header's type label overlaps the title on the assessment and admin pages.
   - Measured gap: −65 px and −33 px at 320–430 px. In production on 0.6.1 the label sits correctly above the title.
   - Cause: in Forma's `@container (max-width: 24em)` rule for `.ef-record-header__title`, a subgrid collapses.
   - Filed upstream as **kemiller2002/forma#179**, with a fix verified by runtime injection (gap 0 at all widths, no overflow).
   - Signal records it as an EXCEPTION test (`test.fail`, owner Forma) and adds ordinary assertions at 768 and 1280 px.
   - **Resolved (WI-0103, 2026-11-09):** the owner authorized the fix chain:
     1. forma#180 released Forma 0.13.1 (asset `sha256:f3ced724…`, verified).
     2. conditor#135 released Conditor 0.10.22, which qualifies it (1,565 checks; the 1.37.1 kickoff-set job installs every native tool from its real release).
     3. echelon-registry#110 cut echelon-current 1.37.1. REG-RU-007 passed in CI against released 0.10.22, and the owner's approval is recorded in `sets/echelon-current/1.37.1.json`.
     4. `conditor upgrade --current` (0.10.22) moved only Forma 0.13.0 → 0.13.1 (plan `sha256:174f340c…`, second-plan drift none).
   - After the upgrade, the record-header tests are ordinary assertions at 320, 390, 768 and 1280 px, and the label-to-title gap is 0 px on both pages.
   - Results: 634/634 .NET tests and 143/143 browser tests pass; `conditor verify`, `limen verify --strict` and `praxis validate` pass.
